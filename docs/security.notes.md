# OT Security Notes

## Security Objective

The simulator includes basic concepts related to safeguarding operational
technology infrastructure.

## Principles Demonstrated

- Asset visibility
- Access awareness
- Change tracking
- Event logging
- Network monitoring
- Fault detection
- Configuration awareness

## Important Limitation

This project does not implement or claim to implement a complete
industrial cybersecurity solution.

It does not connect to production OT equipment or demonstrate
unauthorized-access techniques.

## Portfolio Safety

No real:

- IP addresses
- credentials
- network diagrams
- production configurations
- industrial control parameters
- confidential mining information

should be committed to the repository.
